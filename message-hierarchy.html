Messaging and storytelling

Message Hierarchy

One value proposition at the top, a few key messages under it, and supporting points and proof below.

Common product marketing practice; no single author

  1. Start at the base with the evidence you actually have: data, studies, customers, certifications.

    A validation study with 2,000 patients, a reimbursement code, 120 practices using it.

  2. The specifics that explain each key message.

    Fingertip sample, no lab courier; validated against lab tests; results go to the patient record.

  3. Three or so messages that each give a reason to believe the value proposition.

    A result in ten minutes. Lab-grade accuracy. Fits the GP workflow.

  4. The top: one sentence that everything below supports.

    Make the antibiotic decision during the consultation, not days later.

The question it answers

What do we say first, what comes next, and what proves it?

When to use it

  • Writing a website, sales deck or launch campaign.
  • Teams describe the product in different orders and emphases.
  • Turning a messaging house into channel copy.

When to skip it

  • Before positioning is agreed.

How to run it

  1. List the proof you have before writing any message.
  2. Write key messages that each rest on proof.
  3. Write one value proposition that all key messages support.
  4. Use the hierarchy to order headlines, sections and talk tracks.

Worked example: Lumora Diagnostics

Lumora Diagnostics is a fictional company that makes a rapid blood-test reader for GP clinics.

Proof
A validation study with 2,000 patients, a reimbursement code, 120 practices using it.
Supporting points
Fingertip sample, no lab courier; validated against lab tests; results go to the patient record.
Key messages
A result in ten minutes. Lab-grade accuracy. Fits the GP workflow.
Value proposition
Make the antibiotic decision during the consultation, not days later.

Common mistakes

  • Key messages with no proof beneath them.
  • Too many key messages to remember.
  • A value proposition that just lists the key messages.
