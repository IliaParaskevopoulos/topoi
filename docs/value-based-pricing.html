Pricing and packaging

Value-Based Pricing

Set prices from the value customers get, not from your costs or competitors’ prices alone.

Pricing practice described by Thomas Nagle and colleagues

  1. Group customers by how much value they get, not just by size.

    Paediatric practices get more value than general practices: more antibiotic decisions.

  2. Identify what each segment would use instead, and what it costs them.

    A lab send-out test: free per test, but results take two to three days.

  3. Put a money value on what makes you better, using customer data.

    Fewer return visits and phone calls save about CHF 25 per test.

  4. Price below the value you create, so the customer still gains.

    CHF 12 per test for paediatric practices.

  5. Give sales and customers the tools to see the value.

    A savings calculator on the website and in sales meetings.

The question it answers

What price reflects the value we create for each segment?

When to use it

  • Pricing a new product or entering a new segment.
  • Prices set by cost-plus leave money on the table.
  • Competing against cheaper alternatives.

When to skip it

  • Commodity markets where buyers see no difference between suppliers.

How to run it

  1. Interview customers about outcomes and the alternatives they compare.
  2. Build a simple value model per segment.
  3. Test prices with research such as Van Westendorp or Gabor-Granger.
  4. Arm sales with the value story and a calculator.

Lumora Diagnostics is a fictional company that makes a rapid blood-test reader for GP clinics.

Common mistakes

  • Claiming value customers do not recognise.
  • One price for segments that get very different value.
  • Forgetting to explain the value, so buyers only see the price.
