Go-to-market and launch

SAVE

A B2B update to the 4Ps: solution instead of product, access instead of place, value instead of price, education instead of promotion.

Richard Ettenson, Eduardo Conrado and Jonathan Knowles, 2013

  1. Instead of product: define the offer by the problem it solves.

    Fewer rejected solar-glass batches, not just “high-purity sand”.

  2. Instead of place: make it easy to buy and get help across the journey.

    Online certificate portal, a technical hotline and fixed delivery slots.

  3. Instead of price: show the value relative to the price.

    Cost per good tonne of glass, not price per tonne of sand.

  4. Instead of promotion: give useful information at each stage of the decision.

    An annual purity benchmark and furnace-yield guides.

  5. For each element, check the plan describes the buyer’s side, not yours.

    Halden rewrites its sales deck from product specifications to yield outcomes.

The question it answers

Are we marketing a solution to buyers’ problems, or just a product?

When to use it

  • B2B products sold on outcomes rather than specifications.
  • Sales materials that read like data sheets.
  • Planning content for long buying journeys.

When to skip it

  • Simple consumer products bought on impulse.

How to run it

  1. Write the customer problem first.
  2. Rewrite each P from the buyer’s side, using SAVE.
  3. Check messaging and sales materials against the four elements.
  4. Build education content for each stage of the decision.

Common mistakes

  • Renaming the 4Ps without changing anything.
  • Value claims with no numbers.
  • Education that is really advertising.
